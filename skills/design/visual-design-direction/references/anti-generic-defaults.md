# Anti-generic defaults

These are not forbidden. They are forbidden as automatic defaults. If one appears in your design, write a one-line justification tied to the audience or context in the rationale.

| Default | Why it is a trap | Justified when | Alternatives to try |
| --- | --- | --- | --- |
| Purple-to-blue gradients | Signals "generic AI product"; carries no brand meaning | The brand genuinely owns those hues | A single accent hue from the product's domain; flat color; tint plus texture |
| Dark navy SaaS dashboard | Reads as every other dashboard; lowers legibility of dense data | Users work in dim environments for hours | Light, warm neutrals; true dark with tinted grays chosen deliberately |
| Same card grid on every page | Hides hierarchy; everything looks equally important | Items are genuinely equal, browsable and visual | Tables, lists with rich rows, split layouts, timelines |
| Rounded cards and pill buttons everywhere | Removes distinction between container types | The brand voice is friendly and soft | One shape language with a deliberate exception for primary actions |
| Glassmorphism, neon glow, blurred backgrounds | Costs performance and contrast; rarely supports the task | Decorative marketing surface with proven legibility | Solid surfaces, subtle borders, elevation by tone |
| Oversized hero in task software | Pushes the working surface below the fold | Marketing or campaign pages | Put the primary task above the fold |
| Generic AI copy, filler metrics, decorative feature sections | Teaches users to ignore the interface | Never as filler | Real content, real numbers, specific verbs |
| Arbitrary icons, heavy animation | Adds noise and load | Icons clarify a scan-heavy list; motion explains a change | Text labels; functional motion only |
| Default font without a decision | No identity; may lack needed scripts | The default is the right fit and you can say why | Choose by audience, scripts needed, and tone |

## Self-check before finishing
- Could this screen belong to any product? If yes, find the one element that makes it this product's.
- Is there at least one deliberate choice (type, color, shape, density) you can explain in a sentence?
- Does anything exist purely because it is fashionable?
