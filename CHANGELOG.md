# Changelog

All notable changes are recorded here. The format follows Keep a Changelog and the project uses semantic versioning.

## [0.1.0] - 2026-10-14
### Added
- Playbook: AGENTS.md operating rules, CLAUDE.md import for Claude Code, core principles, routing, 22 workflows, checklists and decision aids.
- 43 skills in the portable SKILL.md format across design, motion, animation production, front end, engineering, specialist, delivery and tooling categories.
- 10 collections, a generated skills manifest and index, and JSON schemas for collections and the manifest.
- Scripts: skill installer (dry run, update, remove, status, conflict-safe), skill validator, instruction validator, collection and index builder, skill lister.
- Standard-library tests for the validators, installer, collections and routing scenarios.
- Documentation: architecture, installation, authoring, compatibility, maintenance; integration notes; GitHub issue and pull request templates; a validation workflow.

### Known gaps
- No license file yet; the maintainer must choose one.
- Not exercised inside live agent sessions; compatibility is documented from vendor documentation only.
