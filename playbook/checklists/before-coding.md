# Before coding

Run this before editing any file. Tick each item or write why it does not apply.

- [ ] I can state the goal in one sentence: "When this is done, ___ is true."
- [ ] I read the project instructions (README, contributing guide, existing agent instruction files).
- [ ] I ran `git status` and know which changes are not mine.
- [ ] I know how to build, run and test the project, and I ran the tests to record a baseline.
- [ ] I read the files I will change and the code that calls them.
- [ ] I found the closest existing example and will follow its structure.
- [ ] Every API, flag, package or file I plan to use exists in the version in use (checked, not remembered).
- [ ] I have acceptance criteria I can verify.
- [ ] My plan is the right size: one line for small tasks, a short plan for medium, a full plan for large or risky.
- [ ] Anything irreversible or external (commit, push, deploy, delete, spend) has authorization, or I will only give commands.
- [ ] I know which workflow and which skills apply (see the routing file) and loaded only those.

If an item fails: stop, fix the gap (inspect, research, ask one question) before coding.
